## Descripción

Esta actividad tiene como objetivo aplicar conceptos básicos de **Programación Orientada a Objetos (POO)** mediante la solución de diferentes ejercicios de programación.

Las soluciones se desarrollan utilizando conceptos como:

- Clases
- Objetos
- Atributos
- Métodos
- Encapsulamiento básico
- Organización del código

## Ejercicios

La carpeta contiene la solución de los siguientes ejercicios:

1. **Ejercicio 8.2**
   - Se desarrolla una interfaz gráfica utilizando Tkinter para ingresar cinco notas de un estudiante y calcular su promedio, desviación estándar, nota mayor y nota menor. El programa incluye botones para calcular los resultados y limpiar los campos, además de validaciones para detectar entradas no numéricas o campos vacíos, correspondientes a los ejercicios adicionales propuestos en el libro.

2. **Ejercicio 8.3**
   - Se desarrolla una aplicación con interfaz gráfica utilizando Tkinter para calcular el volumen y la superficie de diferentes sólidos geométricos. El programa implementa herencia mediante una clase padre FiguraGeometrica y clases hijas para el cilindro, esfera y pirámide, incorporando adicionalmente el cubo y el prisma rectangular. Cada figura cuenta con una ventana para ingresar sus dimensiones, visualizar su imagen y calcular los resultados, utilizando gestión de eventos y validación de entradas.
